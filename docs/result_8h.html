Detailed Description

Typed Result structs, constructors, predicates, and unwrap macros.

Provides Rust-inspired Result types in C without typedef, supporting primitives, enums, structs, unions, pointers, struct pointers, and pointer-to-pointers.

Define a Result struct and inline constructors under an explicit name.

Generates:

  • union <Name>_result_union with Type ok and const char *err via DEFINE_RESULT_UNION
  • struct <Name>_result with enum error_code status and RESULT_UNION(Name) value
  • static inline RESULT(Name) <Name>_result_ok(Type value)
  • static inline RESULT(Name) <Name>_result_err(enum error_code code, const char *error_msg) (coercing ERR_NO_ERROR to ERR_UNKNOWN)

Use this macro for multi-word types, enums, structs, unions, pointers, struct pointers, pointer-to-pointers, and const-qualified types.

Retrieve or unwrap the error message from a Result.

When passed a single argument GET_RESULT_ERR(Res), retrieves the const char * error string from the result variable without accessing the union member directly. When passed three arguments GET_RESULT_ERR(Type, Var, Expr) or four arguments GET_RESULT_ERR(Type, Var, Expr, Name), evaluates Expr and unwraps the error message into const char *Var, throwing ERR_RESULT_IS_OK if Expr was successful.

Parameters
...Variable arguments: either (Res) for 1-arg inspection, or (Type, Var, Expr) / (Type, Var, Expr, Name) for statement unwrapping.

Unwrap a named Result into Var, running a custom handler on error.

Statement macro that evaluates Expr once into RESULT(Name) <Var>_result, executes ... if <Var>_result is an error, asserts that <Var>_result is no longer an error (terminating via THROW_ERROR with ERR_RESULT_IS_ERR otherwise), and declares Type Var = <Var>_result.value.ok;.

Inside the error handler, <Var>_result.status and <Var>_result.value.err are available. The handler must either transfer control (return, break, continue, goto, THROW_ERROR, THROW_ERROR_FMT) or recover by setting <Var>_result.status = ERR_NO_ERROR and <Var>_result.value.ok = ....
