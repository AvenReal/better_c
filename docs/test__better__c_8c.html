Detailed Description

Comprehensive test suite for the better_c macro library.

Tests Result definitions, constructors, predicates, unwrapping macros, error handling, and process termination across various C types.

Retrieve or unwrap the error message from a Result.

When passed a single argument GET_RESULT_ERR(Res), retrieves the const char * error string from the result variable without accessing union members directly. When passed three arguments GET_RESULT_ERR(Type, Var, Expr) or four arguments GET_RESULT_ERR(Type, Var, Expr, Name), evaluates Expr and unwraps the error message into const char *Var, throwing ERR_RESULT_IS_OK if Expr was successful.

Parameters
...Variable arguments: either (Res) for 1-arg inspection, or (Type, Var, Expr) / (Type, Var, Expr, Name) for statement unwrapping.
