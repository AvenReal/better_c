Detailed Description

Error codes and fatal error-reporting macros.

Provides error_code along with THROW_ERROR and THROW_ERROR_FMT for terminating the process with file, function, line, and error-code diagnostics via errx().

Terminate the process with a printf-style formatted error message.

Prints the source file name, function name, line number, error code, and formatted message to stderr, then exits with Code via errx().

Parameters
CodeExit status / error_code value. Evaluated twice; avoid expressions with side effects.
Fmtprintf-style format string literal.
...One or more arguments corresponding to format specifiers in Fmt.
Note
Callers must include <err.h> for errx().
For plain messages without format arguments, use THROW_ERROR.
THROW_ERROR_FMT(ERR_INVALID_ARGUMENT, "Invalid index: %zu", idx);
THROW_ERROR_FMT(res.status, "Operation failed: %s", res.err);
